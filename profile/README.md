# RedWire

**Open infrastructure for a less restricted web.**

We build self-hostable browsing infrastructure: Ultraviolet-based proxies, WISP relays, client tooling and a browser desktop. Everything ships with source and a deployment path.

## Projects

| Project | What it is |
| --- | --- |
| [Infrared](https://infrared.earth) | The flagship proxy - games, apps, cloaking and ad-free deployment |
| [Redline](https://github.com/RRedwire/red-wire/tree/main/services/redline) | Reference Ultraviolet + BareMux + Epoxy/WISP deployment |
| [Signal](https://github.com/RRedwire/red-wire/tree/main/services/signal) | Manifest-driven link hub |
| [WireKit](https://github.com/RRedwire/red-wire/tree/main/packages/wirekit) | Client bootstrap for adding a proxy to any site |
| [Beacon](https://red-wire.org/status/) | Browser-side reachability checks |
| [RedOS](https://github.com/Red60sapphire/redos) | A desktop in a tab, built with OGsWorkshop |
